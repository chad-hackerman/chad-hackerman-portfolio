## Creating Your Own Portfolio Images

When adding images to your actual portfolio:

### Screenshots
- Capture actual application interfaces you've built
- Show your tools and dashboards in operation
- Include clear, high-resolution images
- Remove any sensitive information (passwords, API keys, private IPs)

### Hardware Photos
- Photograph your actual homelab or hardware setups
- Use good lighting and clear angles
- Show cable management and organization
- Demonstrate physical infrastructure you've built

### Terminal Output
- Capture genuine command-line results from your tools
- Show actual scan results, script output, or tool execution
- Redact any sensitive data before capturing
- Use clear, readable terminal settings

### Diagrams
- Create actual network topology diagrams of your infrastructure
- Document real system architectures you've designed
- Use professional diagramming tools (draw.io, Visio, Lucidchart)
- Keep diagrams clean and well-labeled

## Image Best Practices

### File Naming
- Use descriptive names: `project-name-description.png`
- Use lowercase with hyphens
- Avoid spaces and special characters
- Be consistent across all files

### File Optimization
- Resize images to reasonable dimensions (typically 1200px wide max)
- Compress files to reduce repository size
- Use appropriate formats: PNG for screenshots, JPG for photos
- Keep file sizes under 2MB when possible

### Alt Text
All images should have descriptive alt text in markdown:
```markdown
![Descriptive alt text explaining what the image shows](./images/filename.png)
```

### Security Considerations
Before adding ANY image to your portfolio:
- ✅ Remove all passwords and credentials
- ✅ Redact or blur API keys and tokens
- ✅ Remove private IP addresses if applicable
- ✅ Check for any personal or sensitive information
- ✅ Ensure no proprietary company information is visible
